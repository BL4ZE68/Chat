# ForeverLink (scaffold)

Scaffold minimal Next.js 14 + Tailwind CSS + Supabase client.

Quick start:

1. Copy .env.local.example -> .env.local and set NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_ANON_KEY
2. npm install
3. npm run dev

Structure: src/app (app router), lib/supabaseClient.ts, styles/globals.css
